# Figure gallery

Every figure in this documentation is generated by the package itself, with
[CairoMakie](https://docs.makie.org/). Each `plot_*` function returns a `Figure` you can
restyle, compose, or save with [`savefig`](@ref).

```@docs
savefig
xpufp_theme
format_color
```

## Blocks and SNR

```@example gal
using xpuFP, CairoMakie # hide
plot_mx_block_layout(quantize_block(MXFP4, [0.11, -0.35, 0.02, 0.24]))
```

```@example gal
using xpuFP, CairoMakie, Random # hide
plot_mx_block_layout(quantize_block(MXFP4, vcat(0.02 .* randn(MersenneTwister(4), 31), 0.19)))
```

The outlier claims the top of the E2M1 range and, because it alone determines ``S``, the
other 31 values are left using only the bottom of the grid — several fall below the dead
zone and quantize to zero. **Outlier quarantine made visible**, and precisely the
argument for keeping blocks small.

```@example gal
using xpuFP, CairoMakie, Random # hide
plot_format_snr(randn(MersenneTwister(1), 60_000))
```
